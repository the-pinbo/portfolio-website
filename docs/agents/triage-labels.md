# Triage labels

Use these default names when issue triage is requested. Verify existing repository labels first with `gh label list --repo the-pinbo/portfolio-website`. Do not create or rename labels unless that is part of the task.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | Waiting for details from the reporter |
| `ready-for-agent` | Requirements are clear enough for agent implementation |
| `ready-for-human` | Requires human implementation or action |
| `wontfix` | Will not be actioned |
