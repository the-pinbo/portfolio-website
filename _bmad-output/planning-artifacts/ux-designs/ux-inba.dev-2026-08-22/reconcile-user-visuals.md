# User Visual Input Reconciliation

This document reconciles the supplied references into one approved direction. It records existing user decisions; it does not introduce new design choices. The canonical decision history is [`.memlog.md`](./.memlog.md), and the current static interpretation is [the working mock](./.working/direction-riso-tech-editorial.html).

## Coherent input set

| Input | What it contributed | Reconciled role |
|---|---|---|
| Google Antigravity | Quiet Google-caliber craft, large negative space, narrative motion, restrained interactive atmosphere, and a hero that changes state as the story begins. | Experience and motion reference only. Its brand, imagery, particle treatment, and page content are not copied. |
| Current dark portfolio screenshots | Concrete evidence of what felt templated: dark canvas, oversized headings, weak hierarchy, generic process columns, repetitive project rows, and boxed ownership copy. | Diagnostic anti-reference. It defines what the redesign must remove. |
| Original multi-panel clipping-mask reference | The idea of one image becoming a composed editorial object through separated vertical windows. | Structural ancestry for the portrait reveal, reduced from a generic multi-panel image treatment to a deliberate three-window identity mark. |
| Riso portrait (`public/assets/inbase-editorial-portrait.png`) | The native visual language: warm paper, deep navy, coral, imperfect ink, painterly grain, and print registration. | Primary visual source. The page is designed around the portrait rather than forcing the portrait into a separate theme. |
| Three-pillar portrait screenshot | A dominant central face crop with two narrower peripheral crops and rounded vertical masks. | Approved portrait composition. The current mock preserves independent, undistorted source views and prevents a duplicated readable face in the side pillars. |

## Retained

- **Quiet Apple/Google-caliber craft.** Retained because the user repeatedly chose professional restraint, clear hierarchy, and purposeful interaction over visual abundance.
- **Thesis-to-portrait choreography.** Retained because the user explicitly chose to show the opening statement first, then let it resolve and move aside before the portrait enters.
- **Three-pillar portrait mask.** Retained as the central identity device. The center carries the complete face; side windows carry peripheral print content. The user approved the pillar concept and later clarified that the source must remain naturally scaled rather than stretched.
- **A minimal WebGL signature.** Retained as a distinct atmospheric layer, not as a requirement for the pillar hover. Its agreed role is subtle Riso substrate/ink behavior that supports the hero transition, remains calm at rest, and degrades cleanly for touch and reduced motion.
- **Light, continuous paper canvas.** Retained because the user selected a light-only first version that integrates naturally with the portrait's printed paper quality.
- **Modern typography with disciplined scale.** Retained: Instrument Sans for display/body/UI and IBM Plex Mono for sparse technical metadata, with no overlap and a controlled reading hierarchy.
- **Static-first composition and restrained motion.** Retained because the user approved only two major pinned moments and agreed that every section must read clearly before animation is added.

## Transformed

- **Retro PC / voxel language → Riso-tech editorial.** The initial wording was explicitly corrected by the user. Computational character now appears through dither, halftone, low-resolution transitions, ink separation, and registration—not literal pixels, Minecraft blocks, or nostalgic UI chrome.
- **Antigravity's interactive energy → authored digital ink.** The reference's sense of technical depth is translated into a restrained navy/coral substrate and scroll choreography. Recognizable Antigravity visuals, random particles, dotted bands, circles, and copied interaction motifs are excluded.
- **Generic split-image reference → personal three-pillar identity.** The early scenic clipping-mask reference supplied the compositional principle; the portrait screenshot and subsequent review narrowed it to three asymmetric windows with one dominant central crop.
- **Riso texture → concentrated material detail.** Paper fibres, halftone, and ink imperfections remain strongest in the opening substrate, portrait, and selected project imagery. They are not applied uniformly across every surface, preserving clarity and negative space.
- **Project presentation → authored chapters.** The old repeated rows are replaced by one full Smart Filters scroll chapter, shorter immersive ACE io MCP and VisionGuard chapters, then compact editorial chapters for Research, Open Source, Patent, and Track Record.
- **Evidence treatment → quiet artifact links.** Visible “Proof” or “Verified” framing is replaced by literal icon-label links such as Code, Write-up, Paper, Patent, and Certificate beside the relevant work.

## Dropped

- **Dark theme and theme toggle.** Dropped because the user selected a light, subtly textured paper canvas as the only v1 theme.
- **Handwritten caption and handwritten fonts.** Dropped explicitly; human imperfection comes from the print treatment, not script typography.
- **Engineering Loop and any standalone methodology grid.** Dropped because the user identified it as generic filler. Engineering judgment must emerge inside the work stories.
- **Oversized multi-line headings.** Dropped because the current draft's scale damaged hierarchy and flow. Display type must remain proportionate to its content, image, and viewport.
- **Overlapping copy.** Dropped explicitly. Names, thesis text, portrait, and supporting copy must never compete through accidental overlap.
- **Generic project rows, equal cards, and repetitive chapter templates.** Dropped because they made the site read like a portfolio template rather than an authored narrative.
- **“What I Own” boxes.** Dropped as repetitive and clichéd. Ownership is communicated naturally through the case-study narrative.
- **Custom cursor.** Dropped explicitly; the native cursor remains.
- **Skill-logo walls, technology marquees, proficiency bars, and generic tech visuals.** Dropped explicitly. Technology appears only as quiet metadata when it explains an actual project decision.
- **Generic credibility and category labels.** “Featured,” “Award Winning,” “Flagship Systems,” “Proof,” “Verified,” defensive confidentiality copy, and similar labels are excluded. Credibility is carried by the work and its linked artifacts.
- **Fake product UI, fake dashboards, invented metrics, and unsupported visuals.** Dropped. Confidential work uses original conceptual editorial imagery; public work may pair themed covers with real artifacts.
- **Decorative motion patterns.** Random circles, particles, dotted rows, constant marquees, excessive parallax, 3D card tilts, autoplay carousels, and motion without narrative purpose are excluded by the approved anti-patterns and subsequent mock reviews.

## Resulting direction

The combined direction is a light, modern Riso-tech editorial portfolio: thesis-led, scroll-authored, typographically controlled, and technically expressive through restrained ink behavior. The portrait is the central visual identity; WebGL supports the atmosphere and transition; project chapters carry the story; real artifacts quietly support material claims.
