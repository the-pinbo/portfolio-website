- (technique by coach) started Build on What Works
- (insight by coach) The strongest shared behavior is semantic motion: visual movement should show the underlying idea, not decorate it. The portrait demonstrates one image divided across controlled masks; Smart Filters demonstrates one sentence resolving into structured controls.
- (idea by coach) Use separation and registration as a site-wide interaction grammar. Portrait crops separate and align; query phrases detach and settle into filters; Riso ink briefly misregisters and resolves. This creates coherence without repeating one layout.
- (decision by user) The interaction grammar ‘separation, then registration’ is approved.
- (technique by coach) started Failure Analysis
- (insight by coach) The portrait failure is structural, not cosmetic: each pillar currently owns a separately fitted image with object-fit cover, so each crop tries to center meaningful subject matter and duplicates the face. One stage-sized image must sit behind all three masks.
- (insight by coach) The Smart Filters failure is conceptual: the mock explains an invented architecture through a route core, rings, lines, and generic verbs. The understandable product moment is direct language-to-filter transformation, so the visual should privilege input and resolved interface state.
- (decision by user) Portrait pillars remain geometrically aligned and stable. Hover uses only restrained ink-layer separation, halftone sharpening, and contrast response before settling back into register.
- (technique by coach) started Kill the Crown Jewel

- (idea by coach) Adopt a static-first gate: every key frame must read clearly and feel premium as a still image. Motion may enhance separation and registration only after the static hierarchy, cropping, and transformation are already understandable.
- (decision by user) Every major website section must pass a static-first quality gate before motion is designed or implemented.
